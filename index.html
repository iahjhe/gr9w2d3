The parent function: y = x²

A parent function is the most basic form of a group of functions. Every other parabola in this lesson comes from y = x².

Key facts
  • Vertex: (0, 0)
  • Axis of symmetry: x = 0
  • Opens upward

Notice the table is symmetric: f(2) = f(−2).

Reading the equation: three parameters

y = a(x − h)² + k
a changes the width and direction.
Wider, narrower, or flipped.
h moves the graph left or right.
Vertex x-value.
k moves the graph up or down.
Vertex y-value.

So the vertex is (h, k) and the axis of symmetry is x = h.

Quick check: Where is the vertex of y = 2(x − 3)² + 5?
Show answer(3, 5). Axis: x = 3. Opens upward because a = 2 is positive.
Part A

The effect of a on f(x) = ax²

  • If a > 1, the graph is narrower and steeper.
  • If 0 < a < 1, the graph is wider and flatter.
  • If a < 0, the graph opens downward.

Try it: drag the slider and watch the blue curve against the dashed parent.

Worked examples: 2x², ½x², 4x², 7x²

Same vertex (0,0) and axis x = 0. 2x² is narrower than x². ½x² is wider than x².
The bigger |a| is, the narrower the graph.
Activity 1 · Exercise 7

Narrower or wider? Work in pairs

Set 1: f(x) = 2x² and f(x) = 3x²
Set 2: f(x) = −½x² and f(x) = −2x²

1. Make a table of values for x = −2 to 2.
2. Sketch both graphs on graph paper.
3. Which graph is narrower? Which way does each open?

Check answersSet 1: 3x² is narrower (larger |a|). Both open upward. Set 2: −2x² is narrower than −½x². Both open downward because a is negative. Answer: |a| controls width, and the sign of a controls direction.
Part B

The effect of h on f(x) = a(x − h)²

  • If h > 0, the graph moves right.
  • If h < 0, the graph moves left.
  • The shape stays the same. Only the position changes.
Watch the sign! (x + 3)² means h = −3, so the graph moves 3 units left.

Worked examples: (x + 1)² and (x − 1)²

(x + 1)²: vertex (−1, 0), axis x = −1, moves left.
(x − 1)²: vertex (1, 0), axis x = 1, moves right.

Another pair: 2(x + 2)² and 2(x + 3)²

Both graphs move left of the origin. The axes of symmetry are x = −2 and x = −3. Same shape, different positions, because they have the same a = 2.

Both open upward with vertices at (−2, 0) and (−3, 0).

Activity 2 · Exercise 8

Left or right? Human parabola

Graph on paper, then decide if each moves left or right of f(x) = x²:

1. f(x) = (x + 4)² and f(x) = (x + 5)²
2. f(x) = (x − 2)² and f(x) = (x − 3)²

Question: Is there a difference in the graph of the two functions? Why?

Movement option: Stand at x = 0 on a number line on the floor. Step to the vertex x-value of each function called out.
Check answersSet 1 moves left (vertices (−4,0) and (−5,0)). Set 2 moves right (vertices (2,0) and (3,0)). Within each pair the shape is identical. They differ only in position because h is different.
Part C

The effect of k on f(x) = ax² + k

  • If k > 0, the graph moves up.
  • If k < 0, the graph moves down.
  • The vertex is (0, k). The axis of symmetry stays x = 0.

Common slip: k moves the graph vertically but does not change the axis of symmetry.

Worked examples

x² + 2: vertex (0, 2), up 2. x² − 2: vertex (0, −2), down 2. Each y-value in the table shifts by k.
Activity 3 · Exercise 9

Up or down? Vertex race

Graph and decide if each translates upward or downward:

1. y = x² + 3 and y = x² − 2
2. y = x² − 3 and y = x² − 4

Question: Is there a difference in the graph of the two functions? How?

Race: Teams write the vertex of each function. First correct team scores a point.
Check answersSet 1: vertices (0, 3) and (0, −2). The first moves up, the second moves down. Set 2: vertices (0, −3) and (0, −4). Both move down, and x² − 4 is 1 unit lower than x² − 3. Same shape, different heights.
